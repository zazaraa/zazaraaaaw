# Saskia's Personal Landing Page

## Description
Saskia's Personal Landing Page is a personal portfolio website created to introduce myself, showcase my background, interests, and experiences, and provide information about my personal profile.

The website uses a soft pastel color palette with a personal scrapbook-inspired design to create a warm, creative, and visually appealing appearance.

## Website Sections
The website consists of several sections:

- Home – Introduces the website and provides a brief welcome.
- About Me – Presents my personal introduction and academic background.
- About Landing Page – Explains the visual concept and design elements used in the website.
- Experiences – Showcases my organizational activities, volunteering experiences, and training.
- My Interests – Highlights my interests in multimedia, digital content, UI/UX design, and Internet of Things (IoT).
- Contact – Provides links to my social media and contact information.

## Technologies Used
- HTML5
- CSS3
